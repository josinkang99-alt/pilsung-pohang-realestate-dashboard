# 필승부동산 포항 아파트 대시보드

포항시 동별 아파트 실거래 브리핑, Top 10, 추천매물, 지도 및 입지분석을 제공하는 정적 대시보드입니다.

## 공개 화면

GitHub Pages가 `dist/` 폴더를 자동 배포합니다. `main` 브랜치에 변경사항을 푸시하면 배포 워크플로가 실행됩니다.

## 데이터 안내

- 공개 저장소와 브라우저 코드에는 API 키를 포함하지 않습니다.
- 현재 공개 화면의 시장지표와 매물은 브리핑용 표본 데이터입니다.
- 실거래 API 서버 연동 코드는 별도 서버 환경에서 비밀 환경변수를 설정한 경우에만 사용해야 합니다.
